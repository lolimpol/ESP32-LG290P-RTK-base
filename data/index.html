LG290P command channel

Type the part between $ and *; the checksum is added for you. Only Quectel PQTM… commands are accepted. Changes are lost at power-off unless you also send PQTMSAVEPAR; Quectel recommends restarting the receiver afterwards.

Receiver replies (newest first)

Careful: PQTMCFGPROT / PQTMCFGUART can disable NMEA input or change the baud rate and cut this link. If you change the receiver's baud rate, change the GNSS UART baud rate in Settings to match.

Firmware update (OTA)

Upload the application image (firmware.bin) built by PlatformIO / Arduino "Export compiled binary". The new image is written to the inactive slot and only activated after it validates; the device then restarts. RTCM output pauses for a few seconds.
